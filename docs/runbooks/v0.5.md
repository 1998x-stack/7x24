# V0.5 AI evidence runbook

## Upgrade

Back up the SQLite database consistently, then run `news24 db migrate`. The schema moves to version 3 with additive tables: `analysis_results`, `evidence_spans`, `event_clusters` and `event_members`. Older binaries reject a v3 schema; restore the backup for rollback.

## Controlled model use

- Pick a compatible Responses model that is actually accessible to your account; set `OPENAI_API_KEY` only in your runtime environment, never Git.
- Enqueue a particular known UID with `news24 intelligence enqueue --uid ... --model ...`.
- Process using a single worker `news24 jobs run`; do **not** auto-enqueue the entire corpus.
- Inspect `news24 intelligence history --uid ...` and `news24 intelligence evidence --key ...`.
- Optional `OPENAI_BASE_URL` is a provider endpoint override; evaluate compatibility and privacy separately.

## Evaluation

`pytest -q tests/contract/test_evidence_gold.py tests/integration/test_intelligence.py` verifies literal offsets, absent/ambiguous quotes, revisions, caching, failure signaling, rollback, and candidate group identities. CI mocks model responses and makes **zero live external calls**.

## Truth levels

- `TEXT_MATCH_ONLY`: exact unique quote in stored normalized source text; statement not independently verified.
- `NOT_FOUND`: model quote absent.
- `AMBIGUOUS`: quote appears multiple times so no unambiguous offsets.
- `CANDIDATE`: multiple articles may share the same long quotation; not necessarily independent sources or a verified real-world event.
- `REJECTED`: all candidate citations invalid; model job fails explicitly.
- `PARTIAL`: some evidence spans valid, some not; no false overall verification.
- `ACCEPTED`: local response/schema/source-quote checks passed; **not** a human fact-check certification.

A model failure or provider timeout is a failed/retrying task, **not** a neutral sentiment.

## Operational risks

Long model calls can exhaust the V0.4 task lease; use explicit per-job timeouts, single-worker operation and monitor job attempts. Prompt injection in news content must never be treated as a system instruction. API costs and quotas vary by actual model and organization. Run separate security, privacy and source usage reviews before production use.
