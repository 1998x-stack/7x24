# V0.2 runbook

## Setup

Use Python 3.11 or 3.12. In a virtual environment run `python -m pip install -e '.[dev]'`.

Run `news24 doctor --json` (local and offline only) and `news24 test-fixtures tests/fixtures/sina/feed_success.json` before attempting a source request.

## Diagnostic workflow

- Exit 0: command completed successfully (the source may legitimately return an empty page).
- Exit 1: HTTP/schema/environment/output filesystem problem; stderr contains a short error.
- Exit 2: invalid CLI arguments.
- A source failure must not be presented as success/0 items.
- A missing or invalid source timestamp is represented as null.

Run `make lint typecheck test smoke` before opening or approving a PR.

## Legacy

The original `python -m src.main` and `sina7x24_playwright.py` remain available from repository root for regression checks. They are not the supported V0.2 CLI.

## Docker

Use `docker build -t news24:0.2 .` and `docker run --rm news24:0.2 doctor --json`. Use a named data volume if writing persistent exports: `docker run --rm -v news24-data:/data news24:0.2 collect --output /data/latest.jsonl`. The image does not include a scheduler or browser runtime.

## Rollback

Restore the pre-refactor Git reference `archive/pre-refactor-20261103`, or revert the feature PR. V0.2 does not modify existing news files or database schema.

## V0.2 exit criteria

- Offline fixture parse and source-error contract tests pass.
- New Python package wheel builds.
- Both Python CI matrix jobs pass Ruff, Mypy, unit tests and legacy regressions.
- Docker build and container offline smoke pass.
- Any live Sina integration test is explicitly labeled as environment-dependent and is not a prerequisite for offline CI.
